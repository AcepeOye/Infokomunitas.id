
# Infokomunitas.id - Deploy ke Vercel

1. Push folder ini ke GitHub repo baru: infokomunitas-id
2. Di vercel.com > Add New Project > Import repo tersebut
3. Deploy (Vercel otomatis build)
4. Settings > Domains > Add infokomunitas.id
5. Copy DNS record ke IDCloudHost DNS Management

Admin login: admin / admin
Data disimpan localStorage, untuk production gunakan Supabase.
